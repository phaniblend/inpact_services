INPACT — React-TS lesson steps: source order for developers
============================================================

Scope: Authoring or editing lesson flows in
  src/engines/react-ts/inpact_ts*_engine.jsx
(React-TS UI reads these engines directly.)

Use this STRICT phase order for NODES (steps). A phase may span multiple
consecutive steps. Do not move backward to an earlier phase once a later one
has started. Omit a phase only if the lesson truly does not need it.

Canonical reference: .cursor/rules/content-lessons.mdc — section 5a.
Phase labels in code: src/engines/lessonPhasePattern.js (LESSON_CODE_PHASES).


PHASE 1 — IMPORTS
-----------------
- Package and symbol imports.
- When several packages are introduced, prefer one package per step.


PHASE 2 — MODULE SCOPE (outside the component)
----------------------------------------------
- Immediately AFTER imports and BEFORE the component function.
- File-level only: interfaces, type aliases, module-level const, small helpers.
- Do NOT put interfaces or other module-level constructs in the same bucket as
  in-component state (that is phase 4).


PHASE 3 — COMPONENT SHELL
-------------------------
- Component declaration: name, return type (e.g. JSX.Element), minimal skeleton.


PHASE 4 — INSIDE THE COMPONENT (data / hooks)
---------------------------------------------
- useState, other hooks, refs, derived values — anything the UI will read.
- Logical progression: state before handlers that read it (unless the step
  intentionally scaffolds a stub first).


PHASE 5 — JSX STRUCTURE
-----------------------
- Layout, buttons, inputs, copy.
- You MAY omit event wiring here if the lesson splits wiring into phase 7.


PHASE 6 — HANDLERS
------------------
- Functions that update state or run logic.
- If wiring is phase 7, handlers may exist here but not yet be bound in JSX.


PHASE 7 — WIRE AND FINISH
-------------------------
- Bind handlers: onClick, onChange, etc.
- Conditional render, validation polish, export default as required.


SUMMARY (one line)
------------------
Imports → module-level types/helpers (outside component) → component shell →
hooks/state inside component → JSX → handlers → wire handlers to JSX / finish.


OTHER RULES (brief)
-------------------
- Avoid forward references: do not require symbols that have not been introduced
  in the lesson text or seed for that step (or an earlier step).
- Renumber phase text ("Step k of n"), step ids, and sideItems when inserting or
  splitting steps.
- react-ts: prefer explicit return typing (): JSX.Element on the component shell;
  do not use React.FC / React.FunctionComponent in lesson content.

For JSON lesson content under content/, related rules are in the same
content-lessons.mdc file (intro, objectives, feedback, etc.).
