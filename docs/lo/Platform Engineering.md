# Platform Engineering

Lessons and learning objectives.

**{PRODUCTION ENGINEERING #1 :: Observability — Logs, Metrics & Traces}**

LOs:

01
Write structured logs (JSON) with correct log levels and context

02
Avoid the top 5 logging mistakes: sensitive data, missing context, wrong level

03
Instrument code with RED metrics: Rate, Errors, Duration

04
Add distributed tracing with OpenTelemetry

05
Define SLIs, SLOs, and error budgets

06
Build a structured logging middleware for Express

---

**{PRODUCTION ENGINEERING #2 :: Incident Response & Reliability Engineering}**

LOs:

01
Run an incident: detect, declare, communicate, mitigate, resolve

02
Write a blameless post-mortem with 5 Whys root cause analysis

03
Implement a circuit breaker to stop cascading failures

04
Implement retry with exponential backoff and jitter

05
Design health check endpoints (liveness vs readiness)

06
Use feature flags as kill switches for dangerous deployments

---

**{PRODUCTION ENGINEERING #3 :: Deployment Strategies — Zero-Downtime Releases}**

LOs:

01
Implement blue/green deployment with instant rollback

02
Design a canary release with automatic rollback on error spike

03
Use feature flags as deployment decouplers and kill switches

04
Safely run database migrations with zero downtime

05
Design a shadow deployment for risk-free new version testing

06
Know which strategy to use for which risk profile
