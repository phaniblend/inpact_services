# CSS

Lessons and learning objectives.

**{CSS C01 :: Box Model: Why It Exists}**

LOs:

01
See content, padding, border, margin as four distinct layers (and know which one background fills)

02
Understand why 'width' in CSS means 'content width' by default — and why that causes layout surprises

03
Predict total on-screen size from the four layers

04
Use the box model to fix real layout bugs (overflow, misalignment)

---

**{CSS C02 :: box-sizing: Why Layouts Break (and One Fix)}**

LOs:

01
See the broken layout (two 50% columns that overflow) and connect it to content-box

02
Fix it with box-sizing: border-box and see columns sit side by side

03
Use the global reset so every element behaves the same way

04
Reason about 'width as budget': content area = width minus padding and border

---

**{CSS C03 :: Margin Collapse: Why Space Doesn}**

LOs:

01
See all three collapse scenarios and predict 'the larger margin wins'

02
Understand why padding or overflow on the parent stops parent–child collapse

03
Use flexbox + gap when you want consistent spacing without collapse

04
State the rule so you can debug 'why isn't my margin adding?'

---
