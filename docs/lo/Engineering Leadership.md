# Engineering Leadership

Lessons and learning objectives.

**{ENGINEERING LEADERSHIP #1 :: ADRs, Technical Debt & Estimation}**

LOs:

01
Write an Architecture Decision Record (ADR) that future engineers will thank you for

02
Quantify and communicate technical debt to non-engineers

03
Estimate with the PERT formula and communicate uncertainty honestly

04
Triage technical debt: what to fix now vs later vs never

05
Write an RFC to build team alignment before implementation

06
Recognise and avoid the sunk cost fallacy in engineering decisions

---

**{ENGINEERING LEADERSHIP #2 :: Code Review, Mentoring & Engineering Culture}**

LOs:

01
Write code reviews that teach, not just critique

02
Give the SBI feedback model: Situation, Behavior, Impact

03
Structure a 30-60-90 day onboarding plan for new engineers

04
Run effective 1:1s that surface lessons before they fester

05
Build psychological safety so engineers flag lessons early

06
Know when to approve despite disagreement (disagree-and-commit)
